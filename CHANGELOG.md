# Changelog

## 0.2.0

- Reorder gates to match Superpowers: spec (design) is reviewed first,
  then the implementation plan
- spec-review now checks direction and buildability of the design
- plan-review now checks the plan against the spec: coverage, task
  order, executable tasks, verification, cross-task consistency
- Default DECISIONS.md location is shared by spec and plan

## 0.1.0

- Initial skills: plan-review, spec-review, triage-review, decisions
